# ransomware_detect
This project implements a practical ransomware detection and recovery framework using behavioral analysis rather than signature-based methods. It combines entropy-based file inspection, honeypot monitoring, and real-time file system tracking to detect encryption activity early. The system also includes a distributed master–slave password recovery mechanism to accelerate incident response and forensic analysis. Designed with a systems-first approach, the project focuses on reliability, extensibility, and real-world applicability in modern operating environments.
